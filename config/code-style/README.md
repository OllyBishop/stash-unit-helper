# Bishop Java Style

`BishopJavaStyle.xml` is a reusable IntelliJ IDEA code style profile for Java projects.

See [Formatting conventions](CONVENTIONS.md) for the intended rules, examples and reasons behind the settings. Keep that document in sync when changing the profile.

To import it:

1. Open **Settings → Editor → Code Style → Java**.
2. Open the gear menu next to **Scheme**, then choose **Import Scheme → IntelliJ IDEA code style XML**.
3. Select `config/code-style/BishopJavaStyle.xml` and choose the **Bishop Java Style** scheme.

Use **Reformat Code** to apply the profile to selected files. Importing it does not change existing code.

After updating the XML, re-import it and select the updated scheme. If IntelliJ continues using the old settings, restart the IDE.
